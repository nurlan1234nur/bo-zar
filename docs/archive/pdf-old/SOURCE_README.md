# Bayan-Ulgii Marketplace Platform (archived source index)

This index is historical. Redundant Markdown copies were removed after hash verification; links below point to the preserved corrected specification set.

Баян-Өлгий аймаг болон Улаанбаатар хотод сурч, ажиллаж, амьдарч буй Баян-Өлгийн иргэдэд зориулсан төвлөрсөн зар, худалдаа, мэдээллийн платформ.

## Target Stack

- Mobile app: React Native + Expo
- Backend API: NestJS + TypeScript
- Database: PostgreSQL
- Admin web: React Vite + TypeScript
- Deployment: Docker

## MVP Direction

MVP нь mobile-first байна. Эхний хувилбарт хэрэглэгч бүртгүүлэх, нэвтрэх, зар оруулах, зураг upload хийх, хайлт/filter ашиглах, favorite хадгалах, report илгээх, admin moderation хийх боломжууд орно.
