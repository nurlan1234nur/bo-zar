# Archived corrected specifications

This directory preserves the most complete corrected specification set under [`specifications/`](specifications/) and the former root test/acceptance guide under [`legacy-root-guides/`](legacy-root-guides/).

The specifications describe intended MVP behavior at an earlier point in development. They are not current schema, API, folder-layout, or feature-status authority. Byte-identical copies formerly stored in `corrected_docs` and `pdf_new` were removed after hash verification.
