# Prototypes and design references

## Archived Figma export

The standalone Figma-exported marketplace prototype is preserved at:

[`../archive/early-prototypes/marketplace-platform/`](../archive/early-prototypes/marketplace-platform/)

It contains a separate Vite project, mock data, multiple visual themes, UI-library components, and prototype screens for discovery, listings, profile, favorites, chat, and reviews.

## Status

- The prototype is not part of the root pnpm workspace.
- It does not use the production API client or database.
- Its chat, review, profile, and multi-step listing behavior must not be presented as shipped functionality.
- Its attribution file must remain with the archived source.

## How to use it

Use the archive to understand early visual direction and interaction ideas. Validate every adopted pattern against current clients, shared design tokens, product requirements, and accessibility needs. Do not add prototype dependencies to runtime applications merely to preserve its implementation style.
