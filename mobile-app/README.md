# Mobile App

React Native + Expo user-facing marketplace app.

## Main Screens

- Home
- Search
- Ad detail
- Create ad
- Edit ad
- Favorites
- Profile
- Login
- Register

## API

Uses the same NestJS backend as `web-app` and `admin-web`.

Environment variable:

```env
EXPO_PUBLIC_API_BASE_URL=http://localhost:8080/api/v1
```
